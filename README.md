# Gerador de Certificados

Aplicação web para criar certificados de conclusão personalizados. O usuário informa o nome do aluno e as atividades realizadas, visualiza o certificado gerado e pode fazer o download em formato PNG.

## Funcionalidades

- Criar certificados com nome do aluno e lista de atividades.
- Adicionar e remover atividades antes da geração.
- Visualizar o histórico de certificados gerados.
- Baixar o certificado como imagem PNG.
- Interface responsiva para desktop e dispositivos móveis.

## Tecnologias

- [Angular](https://angular.dev/) 20
- TypeScript
- Bootstrap 5
- RxJS
- html2canvas
- UUID

## Pré-requisitos

- Node.js 20 ou superior
- npm
